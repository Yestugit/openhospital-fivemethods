# MemAtlas / RiseMem

MemAtlas 是面向 MemoryRSI 的记忆方法集成与测评框架，工作名为 RiseMem，Python 包名为 `mematlas`。项目帮助研究者将不同记忆方法接入 Agent，并在一致的任务条件下比较后续表现、学习过程与计算开销。

研究主线是 **from RSI-inert to RSI-enabling**：考察不同记忆方法能否帮助 Agent 利用过去经历改善后续执行，分析经验复用、反馈学习和记忆管理的作用及局限。项目的工作分为框架架构、方法集成、测评三个方向。

## 2. 当前代码提供什么

1. **使用记忆方法。**提供方法发现、配置检查、记忆检索、交互记录、反馈学习及状态保存与恢复。一个 Memory 可以连续服务多个任务回合，各方法保留自己的算法和数据库。
2. **接入和比较方法。**当前注册 14 个具名方法和 4 个控制基线，具体清单见方法集成入门。方法切换需要满足输入、模态、反馈和运行条件。
3. **开展测评。**已有 LoCoMo、LongMemEval、自定义数据，以及 OpenHospital 连续诊疗的适配代码，支持训练与测试组织、资源记录和结果输出。

OpenHospital 当前优先验收小规模真实闭环：诊疗、评分、学习、冻结测试和中断恢复。正式参评方法、科室与实验规模按测评任务进一步确认。

## 3. 查看方法与命令

当前团队仓库根目录就是 Python 包目录。在现有工作区的 `MemAtlas/src` 下执行：

```powershell
python -m mematlas methods list
python -m mematlas methods describe baseline_bm25
python -m mematlas --help
```

单独获取团队仓库时，将目录命名为 `mematlas`，在其父目录执行上述命令。命令用于查看方法和参数，不调用模型；实际运行还需准备选定方法的依赖、模型与配置。

医院运行组件统一保存在 `integrations/openhospital_runtime/`，与框架现有的医院适配目录 `integrations/openhospital/` 并列。该目录包含 SDK、医生示例、医院服务、完整病例数据和患者名单。在该目录安装依赖、配置模型密钥后，通过自己的脚本独立启动：

```powershell
python -m pip install -r requirements.txt
python run_openhospital_local.py --dataset train --port 8001
```

框架保留原有的 `integrations/openhospital/` 适配层，默认引用这个独立医院目录。在包父目录执行 `python -m mematlas.integrations.openhospital --help` 查看 RSI 测评参数。三个医院服务、科室名单与测评启动步骤见[测评入门](docs/测评/快速说明.md)。完整开发工作区另有 `examples/`、`tests/` 和 `pyproject.toml`。
