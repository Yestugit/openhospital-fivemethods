# 方法集成入门

## 1. 这个方向负责什么

方法集成负责把有比较价值的记忆方法接入框架，使同一个 Agent 或测评流程能够使用它们。工作包括代表方法调研、原方法理解、接口适配，以及实现差异说明。

公共接口用途保持一致，各方法在内部处理算法、存储和更新差异。用户按方法清单补充必要数据，切换时尽量沿用原有调用流程。——11.01

逐方法使用清单的编写与条件检查任务集中在[项目任务与进展](项目任务与进展.md)。截至 2026-11-01，已完成 Mem0、MemRL、MemoryOS 三份清单；其余方法待迁移后补齐。——11.01

## 2. 当前可发现的方法

下表依据方法目录声明及原生代码整理，概述各方法机制；当前可运行范围见下文。

| 方法 ID | 方法 | 主要机制 |
|---|---|---|
| `mem0` | Mem0 | 从交互中提取事实，维护并检索长期记忆 |
| `a-mem` | A-MEM | 构建记忆笔记，生成属性与关联，更新相关笔记 |
| `graphiti` | Graphiti / Zep | 保存实体、关系与时序事实，进行图与文本检索 |
| `langmem` | LangMem | 提取和整合长期信息，通过 Store 检索 |
| `memorybank` | MemoryBank | 对话摘要、用户信息和带遗忘机制的记忆召回 |
| `memoryos` | MemoryOS | 短、中、长期分层管理，更新用户信息与知识 |
| `expel` | ExpeL | 从成败轨迹提炼经验规则，并召回成功经历 |
| `awm` | Agent Workflow Memory | 从成功轨迹归纳并复用工作流 |
| `m2a` | M2A | 图文记忆管理与多轮证据检索 |
| `reasoningbank` | ReasoningBank | 从成败经历提炼推理经验，按任务查询检索 |
| `memrl` | MemRL | 构建程序化经验，根据反馈更新记忆价值并引导选择 |
| `memq` | MemQ | 价值引导检索，通过来源关系传播经验信用 |
| `memcon` | MemCon | 选择记忆操作，联动 G-Memory 的经验、计划和图结构 |
| `ael` | AEL | 三层记忆、检索策略选择、效用反馈和记忆策略演化 |

另有四个控制基线：`baseline_none` 无记忆，`baseline_markdown` 保存近期反思，`baseline_bm25` 进行词法检索，`baseline_vector` 进行向量检索。

目录入口是 [methods/builtins.py](../../methods/builtins.py) 和 [methods](../../methods/) 下各方法目录。先看方法接收什么经历、返回什么记忆、怎样使用反馈，再进入算法内部。

**目录可发现不等于当前可运行。**目前 14 个方法中，只有 Mem0、MemRL、MemoryOS 已迁移到 Memory v2；其余 11 个方法及 4 个控制基线仍是目录项，暂不能通过公共 `Memory` 执行。

## 3. 当前接入中需要了解的范围

**MemRL、MemQ、MemCon、AEL** 的原生源码位于仓库内；目前只有 MemRL 已迁移到 Memory v2，可通过公共 `Memory` 使用。MemQ 的 epoch 更新和 AEL 的分组维护仍是待迁移方法的原生边界，当前不能作为公共调用流程使用。原生来源和补丁清单位于各自 `_vendor/` 中。

ReasoningBank 的当前实现采用外部成败反馈和单轨迹经验提炼；它也尚未迁移到 Memory v2。

MemRL 在完整经历达到批次或训练尾部时内部更新；不需要 Agent 调用 `evolve()`。MemQ 的 epoch 更新和 AEL 的分组维护边界需在各自迁移后再由公共流程承接。

AEL 的集成范围是记忆组件，不包含金融 Agent。ExpeL、AWM 等方法的原始任务语义与医疗场景有差异；接入 OpenHospital 时需为实际参评方法明确临床数据与反馈映射。当前这些方法仍待迁移到 Memory v2。

使用 M2A 图像能力时，需同时准备图像数据和服务；M2A 当前也尚未迁移到 Memory v2。

以上说明用于理解当前代码范围。与原方法的完整对照仍按方法任务中的保真要求逐项记录。

## 4. 接入一个方法的工作顺序

1. **确认比较价值与可用性。**阅读原方法，记录采用版本和变体，核对 baseline 使用情况、代码条件及接入成本。
2. **明确输入与学习流程。**梳理需要的事件、轨迹、成功标签或其他反馈，以及原生更新时机。
3. **完成适配。**接入公共方法入口，保留算法和数据库；必要的输入、提示或存储变化写清原因。
4. **检查实际行为。**确认记忆形成、检索、反馈、状态保存与恢复能在目标任务中工作，医院接入与测评方向共同联调。
5. **交付说明和配置。**提供简洁使用清单、可运行配置、实现差异与验证结果，让使用者能够接入，其他同学能够复查。

更新日期：2026-10-26。任务依据为工作区 `docs/简要总体任务.md` 和指定的框架需求记录；方法现状依据当前源码。
