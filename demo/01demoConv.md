同时打开程序打印的“记忆目录”，进入其中的用户子文件夹。每轮回答结束后刷新文件。

1. **先积累短期记忆：输入前 10 条。**

   每行作为一次输入：

   ```text
   我做科研时喜欢简短明确的回答，请先给结论，再给必要依据。请简短确认。
   ```

   ```text
   遇到复杂问题，我喜欢分步骤理解，一次只讨论一个主要问题。请简短确认。
   ```

   ```text
   学习一个新框架时，我喜欢先看整体流程，再看关键对象，最后看代码。请简短确认。
   ```

   ```text
   我不喜欢解释中夹杂大量无关细节，只有影响结论的内容才需要展开。请简短确认。
   ```

   ```text
   我是人工智能专业的研究生，正在研究记忆如何帮助 Agent 持续学习。请简短确认。
   ```

   ```text
   我目前正在比较 Mem0 和 MemoryOS 两种记忆方法。请简短确认。
   ```

   ```text
   我计划在本周五的组会上汇报记忆框架的实验进展。请简短确认。
   ```

   ```text
   这次组会我准备介绍框架流程、方法差异和测评结果。请简短确认。
   ```

   ```text
   我的实验使用 Qwen 作为大语言模型，先用小规模数据检查流程。请简短确认。
   ```

   ```text
   比较记忆方法时，我关注回答质量、检索耗时和模型调用量。请简短确认。
   ```

   **观察：**`short_term.json` 中的问答逐渐增加，到第 10 条后应有 10 组；此时 `mid_term.json` 和长期记忆通常仍为空。

2. **触发中期迁移：输入第 11 条。**

   ```text
   请概括我对科研回答长度和表达方式的偏好。
   ```

   **观察：**这一轮写入后，最早的第 1 轮问答迁移到 `mid_term.json`，`short_term.json` 继续保留最近 10 轮。

   在 `mid_term.json` 中重点看：

   | 字段 | 含义 |
   |---|---|
   | `summary` | 主题摘要 |
   | `details` | 归入这个主题的对话页面 |
   | `H_segment` | 当前主题热度 |
   | `analyzed` | 该页面是否已参与长期归纳 |

3. **继续检索相关主题，观察长期归纳：依次输入下面几条。**

   ```text
   我喜欢先看到结论，还是先看详细背景？请根据之前的交流回答。
   ```

   ```text
   当我学习复杂框架时，我偏好怎样的讲解顺序？
   ```

   ```text
   请结合前面的交流，概括以后你应该怎样向我解释科研问题。
   ```

   ```text
   我之前对回答的简洁程度、讨论步骤和细节展开提出过哪些要求？
   ```

   **观察：**相关内容逐渐迁移到中期，检索也会增加匹配主题的访问热度。达到阈值后，MemoryOS 在后续写入时自动归纳长期记忆：

   | 文件 | 重点看什么 |
   |---|---|
   | `long_term_user.json` | `profile` 中是否出现有依据的表达偏好；`knowledge` 中是否出现研究方向等事实 |
   | `long_term_assistant.json` | 是否提取出助手实际做过的事情或相关知识，内容可以为空 |
   | `mid_term.json` | 已处理页面的 `analyzed` 是否变成 `true` |

   **长期归纳没有固定触发轮次**，取决于主题分组和实际检索命中。若尚未出现，可以再问两次与前几条偏好相关的问题。长期归纳后，中期原始页面仍会保留。

4. **最后检查记忆使用。**

   ```text
   请根据你记住的信息，简要介绍我的研究方向，以及我喜欢的科研讨论方式。
   ```

   对照回答和 JSON 内容，观察它实际记住了哪些事实、归纳了哪些偏好。完成后输入 `exit`；本次生成的文件会保留。
